독일 OEM 공급사(Zimmer) 장비 구매의 Procure-to-Pay 전 과정을 담당. 대표 승인, Oracle Fusion 구매요청(PR), 미국 Global Buyer의 PO 전환, 공급사 발주와 PI/OC 검증, Finance 선결제, 송금증 전달과 제작 요청, 제작 완료 후 픽업까지 16단계 SOP로 운영한다. 반복 입력과 서류 대조는 Claude Code 에이전트가 맡고, Submit과 메일 발송은 사람이 결정한다. Owns the full procure-to-pay cycle for equipment from a German OEM supplier (Zimmer): CEO approval, the Oracle Fusion requisition, PO conversion by the U.S. global buyer, supplier ordering with PI/OC checks, Finance prepayment, remittance and production request, and pickup once production is done, run as a 16-step SOP. A Claude Code agent handles the repetitive entry and document matching, while Submit and outgoing emails stay a human decision.

Reads the three handover emails and the supplier thread, separates the in-flight order from the new one, and drafts the CEO approval request in the same format as past approvals.

STEP 3–10
Oracle PR 에이전트 입력
Agent-Driven Oracle Requisition
SOP 워드 문서에 들어 있는 화면 캡처를 꺼내 읽고, Oracle Fusion Redwood 구매요청 화면을 Playwright로 한 칸씩 입력한다. 매 단계 스크린샷으로 값을 확인하고 Submit 직전에서 멈춘다.
Pulls the screenshots out of the SOP Word file, then fills the Oracle Fusion Redwood requisition screen field by field with Playwright, confirming each step by screenshot and stopping right before Submit.

STEP 11–12
PO 전환 요청 · 증빙 정리
PO Conversion · Evidence Filing
PR 자동승인 메일에 붙은 PR PDF를 꺼내 번호·금액·납기를 확인한 뒤, 미국 Global Buyer에게 PO 전환 요청을 보낸다. 주고받은 메일과 서류는 주문건 폴더에 단계 번호를 붙여 저장한다.
Takes the requisition PDF from the auto-approval email, checks number, amount and delivery date, then sends the PO conversion request to the U.S. global buyer. Every email and document is filed into the order's folder with a step number.

STEP 13–16
공급사 발주 · 선결제 · 제작 팔로업
Supplier Order · Prepayment · Production
공급사 양식의 발주서에 Oracle PO 번호를 그대로 넣어 보내고, 회신받은 PI/OC를 PO와 대조한 뒤 Finance에 선결제를 요청한다. 송금이 끝나면 송금증을 보내 제작을 시작시키고 출하 예정일을 받아 픽업까지 챙긴다.
Sends the supplier-format order carrying the Oracle PO number, matches the returned PI/OC against the PO, then requests prepayment from Finance. Once paid, forwards the remittance to start production, gets the ship date and follows through to pickup.
OC 품목·수량·단가·총액을 PO와 재대조, PI 번호 기록OC items, quantities, unit price and total rechecked against the PO; PI number logged
PR·PO·PI·OC 4종 첨부, 월 1·2차 지급일에 맞춘 Finance 지급요청Finance payment request with PR, PO, PI and OC attached, timed to the monthly payment runs
선결제 조건이라 지급이 밀리면 제작·출하도 밀림, 결제 후 약 3~4주 제작Prepayment terms: a late payment delays production and shipment; about 3 to 4 weeks of production after payment
PR 번호를 PO 번호로 보내 PI/OC 재발행이 필요했던 건을 계기로 발주 전 번호 형식(KRR/KR) 확인After a requisition number was once sent as the PO number and the PI/OC had to be reissued, the number format is checked before every order
