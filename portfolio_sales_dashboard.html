Firebase 기반의 실시간 영업 납품처 관리 시스템. 팀원별 분기 목표 추적, 다국어 지원, 대표 보고용 리포트까지 하나의 플랫폼에서 연결한 End-to-End 솔루션. Salesforce(CRM) 예측 데이터를 자동 반영해 수기 입력 간극을 최소화하며, 동일 구조로 커미션 자동계산 등 다른 수기 업무로도 확장 가능하다. A real-time Firebase sales-account management system. Per-member quarterly target tracking, multilingual UI, and an executive report — connected end-to-end in one platform. It auto-syncs Salesforce (CRM) forecast data to minimize manual entry, and the same pipeline extends to other manual workflows such as automated commission calculation.

A custom Salesforce Korea Opportunity report is exported weekly and, after verification, its SO number, dealer, and contract type (Sales Type) are synced into Firestore — replacing manual entry. The same pipeline extends to other manual workflows, such as automated commission calculation.
