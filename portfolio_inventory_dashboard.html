KRP INVENTORY
DASHBOARD

본사 SOP 예측을 포함한 5종의 월간 데이터를 하나의 오프라인 HTML 앱으로 통합. 단순 재고 현황을 넘어, 본사 예측(SOP)과 실제 평균 판매를 대조해 어긋난 SKU를 자동으로 잡아내는 예측 검증 도구. A single offline HTML app that merges five monthly data sources — including HQ SOP forecasts. Beyond stock visibility, it cross-checks HQ forecast against actual average sales to auto-flag SKUs that drift.
