Tkinter 데스크톱 앱. 자재코드와 수량만 입력하면 수입 실적 파일에서 품명·원산지·HTS·단가를 자동으로 찾아오고, 국가별 HTML 인보이스 템플릿 8종 중 해당 시트만 채워 PDF Commercial Invoice를 만든 뒤, 같은 데이터를 수출신고실적 엑셀에도 그대로 기입한다. A Tkinter desktop app — enter just an item code and quantity, and it looks up description/origin/HTS/price from the import record, fills the matching country sheet out of 8 HTML invoice templates to build a PDF Commercial Invoice, then writes that same data straight into the export declaration Excel.

🔎
자재코드 자동 조회
Item Code Lookup
수입 실적 파일을 캐시로 읽어, 자재코드 하나로 품명·원산지코드·HS Code·단가를 한 번에 채운다.
Caches the import record so a single material code fills in description, origin code, HS code, and price at once.
📄
HTML 인보이스 엔진
HTML Invoice Engine
8개국 탭이 담긴 HTML 템플릿에서 BeautifulSoup으로 해당 시트만 남기고, 헤더(Delivery/Date)와 품목 행을 원본 서식 그대로 복제해 동적으로 재구성한다.
Uses BeautifulSoup to isolate the right country tab from an 8-sheet HTML template, then fills the headers and rebuilds item rows dynamically while cloning the original formatting.
🖨️
PDF 자동 변환
PDF Auto-render
Playwright를 우선 사용하고 없으면 헤드리스 Edge/Chrome로 자동 폴백해 A4 인보이스 PDF를 렌더링하고, 작업용 임시 HTML은 자동 삭제한다.
Renders the A4 invoice PDF with Playwright first, auto-falling back to headless Edge/Chrome if unavailable, and deletes the working HTML afterward.
🔀
Rebalance / RMA 모드
Rebalance / RMA Modes
RMA 모드는 시트를 FA LAB으로 고정하고 단가를 10%로, HTS를 반송품 고정 코드(9801.00.1090)로 자동 전환한다.
RMA mode locks the sheet to FA LAB, cuts the price to 10%, and switches the HTS code to the fixed returned-goods code (9801.00.1090).
✏️
즉시 수정되는 미리보기
Editable Live Preview
생성 전 표를 더블클릭으로 바로 고칠 수 있고, 수정 즉시 금액과 합계가 재계산된다.
Double-click any cell in the preview table to fix it — amounts and totals recalculate instantly.
📊
수출신고실적 동시 기입
Export Record, in Sync
PDF를 만든 것과 같은 데이터를 그대로 수출신고실적 엑셀에 append — 같은 정보를 두 번 입력할 필요가 없다.
Appends the exact same data used for the PDF into the export declaration Excel — no need to type the same information twice.
