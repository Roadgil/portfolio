같은 Oracle 로그인 세션을 공유하는 2개 모듈로 구성된 출고(Outbound) RPA. 서비스팀의 DCD/소모품·불량프로모션·챗봇 출고요청 메일을 감지해 Pick Release를 자동 실행하고, 장비납품이동 메일을 감지해 Ship Confirm까지 자동 실행 — 두 모듈 모두 처리 결과 회신 메일 작성까지 완결한다. Outbound RPA built from two modules sharing the same Oracle login session — one detects service-team stock-request emails (DCD/consumables, defect/promotion, chatbot orders) and executes Pick Release; the other detects equipment-delivery-transfer emails and executes Ship Confirm. Both draft the confirmation reply as the final step.

Pick Release Watcher
서비스팀의 DCD/소모품·불량프로모션·챗봇 출고요청 메일을 감지해 Oracle Fusion에서 Pick Release를 자동 실행하고, 처리 결과 회신 메일까지 작성한다.
Detects service-team stock-request emails — DCD/consumables, defect/promotion, and chatbot orders — executes Pick Release directly in Oracle Fusion, and drafts the confirmation reply.
메일 파싱부터 Oracle 트랜잭션 실행까지 무인 처리Unattended end to end — from parsing the email to the Oracle transaction

Oracle SSO 세션이 끊겨도 자동 재로그인 후 계속 진행 (라이브 검증 완료)Auto re-authenticates via SSO on session drop and resumes — verified live
2026년 실제 메일 도착 시간대 데이터를 분석해 체크 주기를 피크 구간 5분, 한산한 구간 20~30분으로 튜닝Tuned polling intervals (5 min at peak, 20–30 min off-peak) from an analysis of real 2026 mail-arrival timestamps
수입/통관 C.I. 대사 자동화와 Oracle 화면이 겹치면 새 탭에서 독립 처리 (양방향 라이브 시뮬레이션으로 검증)Runs in an isolated tab when it overlaps with the import/customs clearance C.I. reconciliation automation — verified via live two-way simulation

ship_confirm_watcher.py
쉽컨펌 자동 처리기
Ship Confirm Watcher
장비납품이동 메일에서 주문번호를 뽑아 Oracle Fusion에서 해당 Shipment의 Ship Confirm Rule을 변경하고 Ship Confirm까지 실행한 뒤, 완료 회신 메일을 작성한다.
Extracts the order number from equipment-delivery-transfer emails, changes the Ship Confirm Rule on the matching Oracle Fusion shipment, executes Ship Confirm, and drafts the completion reply.
주문번호 1건에 Shipment가 여러 개 묶여도 중복 제거 후 각각 순차 처리Dedupes and processes each shipment in turn when one order maps to multiple shipments
pick_release_watcher와 동일한 Oracle 로그인/세션(같은 디버그 포트 Edge 인스턴스)을 그대로 재사용Reuses the exact same Oracle login/session as pick_release_watcher (same debug-port Edge instance)
실제 주문(쁘띠365의원 Picoway)으로 전체 흐름을 실측 검증 — Shipment Open→Closed, Packing Slip 발급까지 확인Verified end to end against a real order (Picoway shipment) — confirmed the shipment moving Open→Closed with a packing slip issued
Edge 콜드 스타트 직후 검색 결과 렌더링 지연으로 생기던 오탐(0건 오판)을 고정 대기 대신 폴링 방식으로 해결Fixed a false-negative (reporting zero results) caused by slow rendering right after a cold Edge start, by polling instead of a fixed wait
Oracle ADF가 버튼 텍스트를 여러 자식 노드로 쪼개 놓는 경우까지 처리하도록 JS textContent 매칭으로 클릭 로직 교체Replaced brittle button-click logic with JS textContent matching to handle Oracle ADF splitting button labels across multiple child nodes
완전 자동화 — 메일 감지부터 Oracle 트랜잭션, 완료 회신까지 사람 개입 없이 처리Fully automated — from mail detection through the Oracle transaction to the completion reply, with zero human touch
