INVENTORY
DASHBOARD

Oracle ERP에서 추출한 5종의 CSV/Excel 데이터를 하나로 통합해, 만료일·로케이터·시리얼/로트 단위까지 재고를 들여다보는 오프라인 단일 HTML 앱. MDM으로 막힌 회사 환경에서도 도는 가벼운 설계. An offline single-file HTML app that merges five Oracle ERP exports into one view — drilling down to expiry date, locator, and serial/lot level. Built lightweight to run even in an MDM-locked corporate environment.

Features

핵심Key 기능Features

📅
만료일 추적
Expiry Tracking
Expiration 필드를 읽어 만료 임박 재고를 별도 컬럼으로 표시. 의료기기 short-expiry 관리에 직접 활용.
Reads the Expiration field to surface near-expiry stock in a dedicated column — built for medical-device short-expiry control.
📍
로케이터·시리얼/로트
Locator & Serial/Lot
창고 로케이터, 시리얼번호, 로트번호 컬럼을 추가해 개별 단위까지 추적 가능.
Adds locator, serial number, and lot columns to trace stock down to the individual unit.
🔮
예측 검증
Forecast Check
KRP 시트에서 AVG 2025 vs AVG FCT(6)를 비교해 30% 이상 차이나는 SKU를 자동 플래그.
The KRP sheet compares AVG 2025 vs AVG FCT(6) and auto-flags any SKU diverging more than 30%.
💾
오프라인 영속성
Offline Persistence
IndexedDB로 데이터를 저장하고 localStorage에 월간 KPI 스냅샷을 누적해 추세를 본다.
Stores data in IndexedDB and accumulates monthly KPI snapshots in localStorage to show trends.
📤
Excel 내보내기
Excel Export
회사 모바일 Outlook의 JS 차단(MDM) 이슈로, KRP 공유 출력을 SheetJS 기반 .xlsx로 전환.
Because corporate mobile Outlook blocks JS (MDM), the KRP shared output was switched to SheetJS-based .xlsx.
🧩
KRP 시트 재현
KRP Sheet Replica
기존 Excel 레이아웃을 그대로 재현한 KRP 탭으로, 현업이 익숙한 화면 그대로 사용.
A KRP tab that replicates the existing Excel layout so the team works in a familiar view.
