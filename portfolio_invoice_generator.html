🗃️
559품목 단가 DB
559-item Price DB
전 품목 단가를 PRICE_DB로 내장. 품목코드 입력 시 단가가 자동으로 채워진다.
All item prices embedded as PRICE_DB. Enter an item code and the price fills in automatically.
🔤
코드 별칭 시스템
Code Alias System
CODE_ALIAS로 현업 약어를 정식 코드로 매핑 (예: DCD → FIN101110). Carebot 포맷도 파싱.
CODE_ALIAS maps field shorthand to official codes (e.g. DCD → FIN101110) and parses the Carebot format.
🔡
대소문자 무관 조회
Case-insensitive Lookup
PRICE_DB_CI로 대소문자 구분 없이 코드를 찾아, 입력 실수에도 정확히 매칭.
PRICE_DB_CI resolves codes regardless of case, matching correctly even with typos.
➕
유연한 구분자
Flexible Separators
+ 와 쉼표를 모두 품목 구분자로 인식해, 한 줄에 여러 품목을 자유롭게 입력.
Both + and commas work as item separators, so multiple items can be entered freely on one line.
🏷️
프리미엄 할인 로직
Premium Discount Logic
프리미엄 센터를 자동 판별해 10% 할인을 적용. 거래처 유형별 가격을 자동 산출.
Detects premium centers and applies a 10% discount, computing prices per account type.
🖋️
투명 도장 오버레이
Stamp Overlay
투명 처리된 도장 이미지를 명세서에 합성해, 출력물에 바로 날인된 형태로 완성.
Composites a transparency-processed stamp image onto the statement, so the output looks pre-sealed.
